# 🎯 첫 번째 미니웹앱 프로젝트: 프리랜서 실수령액 계산기

> **"축하합니다! 이 문서를 따라 하면 오늘 당장 나만의 첫 디지털 상품 프로토타입이 완성됩니다."**

---

## 📌 1. 프로젝트 개요
- **목표:** 계약 금액을 넣으면 3.3% 사업소득세를 뺀 실수령액을 1초 만에 알려주는 심플 모바일 계산기
- **소요 예상 시간:** 15분
- **필요한 코딩 실력:** 0 (Ctrl+C, Ctrl+V와 브라우저 더블클릭만 할 줄 알면 끝!)

---

## 🧪 2. 바로 실행해볼 수 있는 완성형 코드 예제

아래 코드는 바로 작동하는 완전한 단일 HTML 파일입니다.  
내 컴퓨터 바탕화면이나 이 폴더에 `calculator.html`이라는 이름으로 저장하고 더블 클릭하면 브라우저에서 즉시 작동합니다!

<body>
  <div class="card">

    const input = document.getElementById('amount');
    const grossDisplay = document.getElementById('grossDisplay');
    const taxDisplay = document.getElementById('taxDisplay');
    const netDisplay = document.getElementById('netDisplay');

    function calculate() {
      const val = parseInt(input.value) || 0;
      const tax = Math.floor(val * 0.033);
      const net = val - tax;

      grossDisplay.textContent = val.toLocaleString() + '원';
      taxDisplay.textContent = '-' + tax.toLocaleString() + '원';
      netDisplay.textContent = net.toLocaleString() + '원';
    }

    input.addEventListener('input', calculate);

    function copyResult() {
      const text = `[프리랜서 실수령액 계산 결과]\n계약금액: ${grossDisplay.textContent}\n원천징수(3.3%): ${taxDisplay.textContent}\n실수령액: ${netDisplay.textContent}`;
      navigator.clipboard.writeText(text).then(() => {
        alert('계산 결과가 클립보드에 복사되었습니다! 카톡 등에 붙여넣어보세요.');
      });
    }

    calculate();
  </script>
</body>
