# 🚀 Vibe to MRR (바이브코딩 부업 수익화 볼트)

> **코딩 완전 초보를 위한 AI 바이브코딩 기반 외주 & 디지털 상품 수익화 사령탑**

이 볼트는 AI(ChatGPT, Claude, Cursor, Antigravity 등)와 함께 코딩 지식 없이도 실제 작동하는 제품을 만들고, 부업 소득(외주 및 디지털 상품)을 창출할 수 있도록 돕는 지식 관리 및 프로젝트 트래커입니다.

---

## 🧭 시작하기

옵시디언에서 가장 먼저 아래 문서를 열어보세요!
- 🏠 **[[00_대시보드_수익화_사령탑]]**: 전체 진행 현황 및 이번 주 To-Do
- 🗺️ **[[01_4단계_단계별_실행_로드맵]]**: 1단계 기초부터 4단계 외주 수주까지의 12주 코스
- 💰 **[[02_수익화_트랙_전략_가이드]]**: 외주(Active)와 디지털 상품(Passive)의 완벽한 조화
- 🛠️ **[[03_옵시디언_200%_활용법]]**: 양방향 링크, 태그, 템플릿 스마트 사용 팁
