# 🚀 1분 만에 내 웹사이트 전 세계에 배포하기 (무료 배포 완벽 가이드)

> **"컴퓨터 안에 갇혀 있는 코드는 0원입니다. 링크(URL)가 생겨 카톡으로 공유되는 순간부터 '돈'이 됩니다!"**

바이브코딩으로 만든 웹사이트(`HTML` 파일)를 전 세계 누구든 접속할 수 있는 실제 웹사이트 주소(`https://...`)로 만드는 작업을 **'배포(Deployment)'** 또는 **'호스팅(Hosting)'**이라고 부릅니다.

월 비용 0원으로, 개발 서버 설정 없이 **클릭 3번 만에 배포하는 가장 쉽고 강력한 방법 2가지**를 단계별로 알려드립니다.

---

## ⚡ 방법 1: Vercel (버셀) - 전 세계에서 가장 빠르고 쉬운 방법 (강력 추천!)

Vercel은 현재 전 세계 실리콘밸리 스타트업과 프론트엔드 개발자들이 가장 사랑하는 무료 배포 플랫폼입니다.

### 🎯 왜 Vercel인가?
- ✅ **100% 무료:** 개인 프로젝트 및 소규모 웹사이트는 평생 무료입니다.
- ✅ **초고속 CDN:** 한국은 물론 미국, 유럽 어디서 접속해도 0.1초 만에 로딩됩니다.
- ✅ **무료 보안인증서(HTTPS):** 자물쇠 아이콘(`https://`)이 자동으로 적용됩니다.

### 🛠️ 실전 배포 3단계 (따라하기)

#### 1단계: Vercel 계정 만들기
1. [vercel.com](https://vercel.com)에 접속합니다.
2. 우측 상단 **Sign Up** 클릭 → **Continue with GitHub** (깃허브 계정으로 1초 로그인)을 선택합니다.

#### 2단계: 프로젝트 업로드 (가장 쉬운 GitHub 연동)
1. 방금 푸시한 여러분의 GitHub 저장소(`https://github.com/space-cap/vibe-to-mrr`)가 이미 있다면,
2. Vercel 대시보드에서 **"Add New..."** → **"Project"** 클릭.
3. 목록에서 내 저장소 이름(`vibe-to-mrr`) 옆의 **"Import"** 버튼 클릭!
4. 설정 건드릴 것 없이 파란색 **"Deploy"** 버튼만 누르면 15초 만에 폭죽이 터지며 배포가 완료됩니다! 🎆

> 💡 **HTML 파일 단독 배포 (드래그 앤 드롭 팁):**  
> GitHub 없이 파일 하나(`calculator_sample.html` 등)만 바로 띄우고 싶다면:  
> 폴더 안에 `index.html`이라는 이름으로 저장한 뒤, [Netlify Drop](https://app.netlify.com/drop)에 폴더째 마우스로 끌어다 놓으면 5초 만에 즉시 링크가 나옵니다!

#### 3단계: 나만의 링크 확인 & 스마트폰 테스트
- 배포가 끝나면 `https://vibe-to-mrr-xxxx.vercel.app` 형태의 고유 링크가 발급됩니다.
- 이 링크를 스마트폰 카카오톡 '나와의 채팅'에 붙여넣고 눌러보세요. 내 폰에서 내가 만든 계산기가 진짜 어플처럼 작동합니다!

## 🌐 방법 2: GitHub Pages (깃허브 페이지) - 깃허브 안에서 바로 끝내기

이미 코드가 GitHub에 올라가 있다면 별도의 외부 사이트 가입 없이도 무료 호스팅을 켤 수 있습니다.

### 🛠️ 세팅 방법 (30초 컷)
1. 웹 브라우저에서 내 GitHub 저장소 페이지로 이동합니다.
2. 상단 메뉴 탭에서 **Settings** (톱니바퀴) 클릭.
3. 왼쪽 사이드바 메뉴 중 **Pages** 클릭.
4. **Build and deployment** 섹션의 Source에서:
   - Branch: `main` 선택
   - 폴더: `/ (root)` 선택 후 **Save** 클릭!
5. 1~2분 뒤 새로고침하면 상단에 `https://깃허브아이디.github.io/vibe-to-mrr` 주소가 생성됩니다.

## 🏷️ 전문가 팁: 나만의 도메인(내이름.com / 회사이름.kr) 3분 만에 연결하기

외주 클라이언트에게 납품하거나 진지한 디지털 상품을 판매할 때는 Vercel 기본 주소 대신 깔끔한 도메인을 연결해야 신뢰도가 올라갑니다.

### 1. 도메인 구매 (연 1~2만 원)
- [가비아(Gabia)](https://www.gabia.com) 또는 [호스팅케이알](https://www.hosting.kr)에서 원하는 주소(예: `fast-calc.com` 또는 `mybrand.kr`)를 검색해 구매합니다.

### 2. Vercel에서 도메인 연결
1. Vercel 프로젝트 대시보드 → **Settings** → **Domains** 클릭.
2. 내가 산 도메인 주소 입력 후 **Add** 클릭.
3. Vercel이 친절하게 화면에 안내해 주는 **CNAME 레코드 값**(예: `cname.vercel-dns.com`)을 복사합니다.
4. 가비아의 [DNS 관리] 메뉴에 들어가서 방금 복사한 CNAME 값을 붙여넣으면 끝! (보통 5~10분 후 도메인으로 접속됩니다.)

## 🚨 초보자가 가장 많이 겪는 배포 트러블슈팅 3원칙

### 1. 화면에 "404 Not Found" 에러가 떠요!
- **원인:** 웹 서버는 기본적으로 첫 화면으로 **`index.html`**이라는 이름의 파일을 찾습니다.
- **해결책:** 대표 파일 이름을 반드시 소문자 `index.html`로 변경해 두세요!

### 2. 이미지가 엑스박스(X)로 깨져요!
- **원인:** 이미지 파일 경로가 내 컴퓨터 폴더 경로(`C:\Users\...`)로 되어 있거나, 대소문자가 틀린 경우입니다.
- **해결책:** 상대 경로(예: `./images/logo.png`)로 작성하거나, 이미지를 Imgur나 무료 이미지 호스팅에 올린 웹 URL로 지정하세요.

### 3. 코드를 수정했는데 웹사이트에 바로 안 바뀌어요!
- **원인:** 브라우저가 과거 화면을 기억하고 있는 '캐시(Cache)' 현상입니다.
- **해결책:** `Ctrl + F5` (강력 새로고침)를 누르거나, 스마트폰 브라우저 창을 껐다 켜보세요.
