# 📖 코딩 완전 초보를 위한 핵심 웹 용어 10선

> **"개발 용어는 외국어가 아니라 '주방'이나 '건축'에 비유하면 1분 만에 이해할 수 있습니다!"**
> 바이브코딩할 때 AI가 자주 쓰는 단어 10가지만 알아두면, AI와의 대화가 2배 더 즐거워집니다.

---

### 1. HTML (웹페이지의 뼈대)
- **비유:** 건물의 콘크리트 골조와 철근, 혹은 사람의 뼈
- **설명:** "여기에 제목 글자가 들어간다", "여기에 버튼이 있다", "여기에 사진이 있다"라고 뼈대를 정의하는 언어입니다.

### 2. CSS (웹페이지의 옷과 인테리어)
- **비유:** 벽지, 조명, 예쁜 페인트칠, 사람이 입는 옷과 화장
- **설명:** 글자 색상을 파란색으로 바꾸고, 버튼 모서리를 둥글게 깎고, 화면을 깔끔하게 배치하는 디자인 언어입니다.

### 3. JavaScript (JS - 웹페이지의 두뇌와 손발)
- **비유:** 건물의 엘리베이터 모터, 자동문 센서, 사람의 뇌와 근육
- **설명:** 사용자가 버튼을 클릭했을 때 숫자가 계산되거나, 팝업창이 열리거나, 화면이 슥 바뀌는 "동작"을 담당합니다.

### 4. 프론트엔드 (Frontend - 손님이 보는 매장 홀)
- **비유:** 카페의 예쁜 카운터, 메뉴판, 테이블
- **설명:** 사용자의 스마트폰이나 브라우저 화면에 직접 눈으로 보이고 손으로 만져지는 모든 영역입니다. 바이브코딩 초보 부업은 대부분 프론트엔드 중심으로 시작합니다!

### 5. 백엔드 (Backend - 손님 눈에 안 보이는 주방과 창고)
- **비유:** 카페 주방의 에스프레소 머신, 냉장고, 회원 장부
- **설명:** 비밀번호 암호화, 데이터베이스(DB) 저장, 결제 승인 처리처럼 서버 컴퓨터 뒤편에서 몰래 돌아가는 기술입니다.

### 6. API (식당의 웨이터 / 배달 라이더)
- **비유:** 손님(프론트엔드)이 "아메리카노 주세요"라고 주문하면 주방(백엔드)에 전달하고 커피를 가져다주는 **웨이터**
- **설명:** 다른 프로그램이나 AI에게 "날씨 정보 좀 줘", "AI 답변 좀 보내줘" 하고 요청하고 받아오는 통로입니다.

### 7. 로컬호스트 (localhost / 내 컴퓨터 안의 비밀 실험실)
- **비유:** 내 방 안의 작업 책상
- **설명:** 아직 인터넷 세상에 공개하지 않고, 오직 내 컴퓨터 브라우저에서만 미리 테스트해보는 주소(보통 `localhost:3000` 또는 `127.0.0.1` 같은 형태)입니다.

### 8. 배포 (Deploy / 호스팅)
- **비유:** 내 방에서 만든 요리를 세상 앞 거리 매장에 정식으로 오픈하는 것
- **설명:** 내 컴퓨터에만 있던 HTML 파일을 24시간 켜져 있는 클라우드 서버에 올려서, 전 세계 누구든 링크만 누르면 볼 수 있게 만드는 작업입니다. (무료 플랫폼: Vercel, Netlify)

### 9. 도메인 (Domain / 인터넷 주소)
- **비유:** 건물의 실제 도로명 주소 (예: 서울시 강남구 테헤란로 ...)
- **설명:** 원래 컴퓨터 주소는 `192.168.1.1` 같은 복잡한 숫자인데, 사람들이 외우기 쉽게 `naver.com`, `toss.im`처럼 이름을 붙여준 것입니다.

### 10. 반응형 웹 (Responsive Web)
- **비유:** 고무줄 바지, 카멜레온
- **설명:** PC 모니터 넓은 화면에서 볼 때나, 스마트폰 좁은 화면에서 볼 때나 화면 크기에 맞춰서 레이아웃이 알아서 착착 예쁘게 정렬되는 웹사이트를 말합니다. 외주 납품 시 필수 조건입니다!
