# 🤖 코딩 초보자를 위한 AI API 연동 3단계 가이드

> **"내 웹사이트에 ChatGPT나 Claude의 똑똑한 두뇌를 장착하는 순간, 평범한 웹페이지가 '돈을 부르는 AI 서비스'로 변신합니다!"**

단순한 계산기나 텍스트 복사 도구는 5,000원에 팔리지만, **"내 고민을 듣고 맞춤 조언을 해주는 AI 운세/상담 웹앱"**이나 **"버튼 하나로 마케팅 문구를 뽑아주는 AI 툴"**은 월 구독료를 받거나 건당 50만 원 이상의 외주 프로젝트가 됩니다.

초보자도 10분 만에 이해할 수 있는 AI 연동의 모든 것을 정리해 드립니다.

---

## 🍽️ 1. API란 무엇인가? (가장 쉬운 비유)

- **손님(내 웹사이트 방문자):** "오늘 내 시험 운세 좀 봐줘!"라고 입력창에 적음.
- **웨이터(API - Application Programming Interface):** 손님의 질문을 쟁반에 담아서 주방으로 가져감.
- **특급 요리사(OpenAI / Claude / Gemini):** 질문을 읽고 맛깔나는 운세 조언을 3초 만에 작성함.
- **웨이터(API):** 요리사가 쓴 글을 다시 손님 화면에 예쁘게 띄워줌.

즉, 여러분이 AI 모델을 직접 만들 필요가 없습니다. **미국 최고의 천재들이 만든 거대 AI 두뇌를 월 1,000~2,000원 정도의 요금만 내고 심부름꾼(API)을 통해 빌려 쓰는 것**입니다!

---

## 🔑 2. AI 두뇌 사용권(API Key) 발급받기 (3단계)

요리사에게 주문을 넣으려면 **"내가 합법적으로 돈 내고 쓰는 사용자다"**라는 일종의 디지털 출입증인 **API Key(열쇠)**가 필요합니다.

### 🌟 추천: Google Gemini API (초보자에게 1순위 추천 - 완전 무료!)
1. [Google AI Studio](https://aistudio.google.com/)에 구글 아이디로 로그인합니다.
2. 파란색 **"Get API key"** 버튼 클릭.
3. **"Create API key"** 클릭하면 영어와 숫자가 섞인 긴 열쇠(`AIzaSy...`)가 나옵니다.
4. **비용:** 일정 사용량까지 **100% 완전 무료**입니다! 초보 연습용으로 최고입니다.

### 🌟 대안: OpenAI (ChatGPT) 또는 Anthropic (Claude)
- [OpenAI 플랫폼](https://platform.openai.com) 또는 [Anthropic 콘솔](https://console.anthropic.com) 가입 후 API Key 생성.
- 최초 가입 시 5달러(약 7,000원)만 충전해두면 수천 번의 답변을 뽑아낼 수 있습니다. (답변 1회당 약 1~2원 수준!)

---

## 🚨 3. 초보자가 반드시 알아야 할 '열쇠 도난 방지' 3원칙 (★매우 중요!)

API Key는 내 신용카드와 연결되어 있는 열쇠입니다. 이것을 남들에게 들키지 않는 법을 꼭 기억하세요!

1. **GitHub 공개 저장소에 그대로 올리지 마세요:**
   - 코드 안에 열쇠(`AIzaSy...`)를 글자 그대로 적은 채로 GitHub에 올리면 로봇들이 훔쳐갈 수 있습니다.
2. **초보자 연습 시에는:**
   - 개인 컴퓨터에서 테스트할 때만 잠깐 입력해서 확인하거나,
   - 사용자에게 *"본인의 Gemini 무료 API 키를 넣어보세요"*라고 입력받는 방식으로 웹앱을 만들면 내 지갑이 100% 안전합니다!
3. **실전 배포 시에는:**
   - Vercel의 **Environment Variables(환경 변수)**라는 비밀 보관소에 열쇠를 넣어두면 AI가 알아서 안전하게 숨겨줍니다.

## 💡 4. AI에게 이렇게 명령하세요 (바이브코딩 프롬프트)

AI 코딩 도구에게 아래처럼 말하면 알아서 연동 코드를 100% 짜줍니다:

```markdown
내가 만든 웹페이지에 Google Gemini API를 연동하고 싶어.
사용자가 고민을 텍스트창에 적고 [운세 보기] 버튼을 누르면,
Gemini에게 "너는 유쾌하고 따뜻한 20대 대학생 타로 상담가야. 다음 고민에 대해 긍정적인 해결책을 3줄로 말해줘"라는 프롬프트를 보내서 답변을 받아 화면에 타로 카드와 함께 띄워줘.
초보자도 따라 할 수 있게 친절한 주석을 달아줘.
```
