# 💡 바이브코딩 실전 치트키 프롬프트 모음

> **"AI에게 좋은 질문을 던질수록, 개발 속도는 10배 빨라지고 코딩 에러는 10분의 1로 줄어듭니다!"**
> 아래 프롬프트 박스의 내용을 그대로 복사(Copy)해서 AI(Antigravity, Claude, ChatGPT, Cursor 등)에게 입력해 보세요.

---

## 🚀 1. 프로젝트 첫 시작 프롬프트 (초대박 기본 세팅)

새로운 웹페이지나 미니앱을 처음 만들 때 사용하는 마스터 프롬프트입니다.

```markdown
너는 세계 최고 수준의 풀스택 웹 개발자이자 UI/UX 디자이너야.
나는 코딩을 잘 모르는 비전공자 기획자야.

[내가 만들고 싶은 서비스]:
- 서비스 이름: (예: 프리랜서 실수령액 계산기)
- 주요 타깃 사용자: (예: 3.3% 사업소득 프리랜서 및 N잡러)
- 핵심 기능 3가지:
  1. 계약 금액 입력 (월급여 or 건당 금액)
  2. 3.3% 원천징수 세금 및 4대보험 공제 선택 계산
  3. 최종 실수령액 결과 카드 표시 및 결과 클립보드 복사 기능

[기술 및 디자인 요구사항]:
1. 초보자도 바로 띄울 수 있도록 단일 HTML 파일(내부에 CSS와 JS 포함)로 작성해줘.
2. 디자인은 애플(Apple)이나 토스(Toss) 스타일처럼 극도로 깔끔하고 현대적인 다크/라이트 모드 인터페이스를 적용해줘.
3. 모바일 스마트폰 화면에서도 완벽하게 동작하는 반응형(Mobile-friendly)으로 만들어줘.
4. 모든 코드는 주석으로 어떤 역할을 하는지 한국어로 친절하게 설명해줘.
5. 내가 이 코드를 어떻게 컴퓨터에서 실행하고 테스트할 수 있는지 3줄로 쉬운 가이드도 함께 적어줘.
```

## 🎨 2. 디자인 업그레이드 프롬프트 (촌스러움 탈출)

AI가 처음 만들어준 코드가 밋밋하고 1990년대 웹사이트 같다면 이 프롬프트를 던져보세요!

```markdown
지금 기능은 아주 마음에 드는데, 디자인이 조금 밋밋해!
요즘 2026년 트렌드에 맞는 감각적인 프리미엄 디자인으로 업그레이드해줘.

- 폰트는 Pretendard 또는 Inter 같은 모던 웹폰트를 적용해줘.
- 둥근 모서리(Border-radius), 은은한 그림자(Box-shadow), 부드러운 호버 애니메이션(Hover transition)을 추가해줘.
- 중요한 버튼이나 하이라이트 숫자에 세련된 그라디언트(Gradient) 포인트를 줘.
- 여백(Padding과 Margin)을 시원시원하게 넓혀서 답답하지 않게 만들어줘.
```

## 🚨 3. 에러 해결 프롬프트 (당황하지 않고 고치기)

화면에 아무것도 안 나오거나 버튼을 눌러도 반응이 없을 때 복붙하는 프롬프트입니다.

```markdown
방금 준 코드를 실행했는데 아래와 같은 문제가 발생했어!

[증상 / 브라우저 개발자 도구(F12) 콘솔 에러 내용]:
(여기에 에러 문구 또는 "버튼을 눌러도 계산 결과가 안 나와요" 적기)

나는 코딩 초보자니까,
1. 왜 이런 문제가 생겼는지 비유를 들어 아주 쉽게 1문장으로 설명해줘.
2. 어떤 부분을 고치면 되는지 수정된 전체 코드를 누락 없이 완성본으로 다시 전달해줘.
```

## 📱 4. 모바일 반응형 & 카카오톡 공유 최적화 프롬프트

```markdown
스마트폰 카카오톡이나 인스타그램에서 링크를 공유했을 때 예쁘게 뜨도록 오픈그래프(OG Tag)와 모바일 뷰포트를 추가해줘:

- 제목(Title): (예: 프리랜서 실수령액 계산기 - 1초 만에 확인)
- 설명(Description): (예: 3.3% 원천징수 떼고 내 통장에 실제로 들어오는 돈은 얼마?)
- 모바일에서 확대되거나 화면이 잘리지 않도록 viewport 메타 태그를 완벽하게 세팅해줘.
```

## 💸 5. 수익화 장치 추가 프롬프트 (후원/문의 버튼)

```markdown
웹페이지 맨 하단(Footer)에 사용자 반응을 유도하는 수익화 섹션을 추가해줘:

1. "개발자에게 커피 한 잔 후원하기 (Buy Me a Coffee)" 깔끔한 버튼 (클릭 시 링크 이동)
2. "외주 및 기능 추가 문의하기" 카카오톡 오픈채팅방 또는 이메일 연결 버튼
3. 우측 하단에 고정되는 '공유하기 (링크 복사)' 플로팅 버튼
```
