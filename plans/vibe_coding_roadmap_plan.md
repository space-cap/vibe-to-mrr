# 🚀 바이브코딩 기반 부업 수익화 & 옵시디언 시스템 구축 계획

안녕하세요! 코딩을 전혀 몰라도 AI(ChatGPT, Claude, Cursor, Antigravity 등)와 호흡을 맞추는 **바이브코딩(Vibe Coding)**을 통해 부업 수익(외주/프리랜싱 + 디지털 상품)을 달성할 수 있는 완벽한 로드맵 시스템을 설계했습니다.

이 볼트(`vibe-to-mrr`)가 단순한 메모장이 아니라 **나만의 부업 사령탑(Control Tower)**이 될 수 있도록 옵시디언의 양방향 링크(`[[]]`), 체크리스트, 템플릿을 풀세트로 구성합니다.

---

## 📌 1. 전체 목표 및 방향성

| 구분 | 내용 |
| :--- | :--- |
| **목표 대상** | 코딩 완전 초보 (비전공자/직장인 부업러) |
| **핵심 무기** | 바이브코딩 (AI 프롬프팅 + 빠른 시제품 제작) |
| **수익화 트랙** | ① 디지털 상품 (소형 웹앱, 계산기/진단툴, 크롬 확장프로그램, 템플릿)<br>② 외주/프리랜싱 (랜딩페이지 제작, 소상공인 웹사이트, 업무 자동화 툴) |
| **작업 환경** | 옵시디언 (체계적인 지식 관리, 프로젝트 추적, 프롬프트 자산화) |

├── 🗺️ 01_4단계_단계별_실행_로드맵.md      # 초보 탈출부터 첫 100만 원까지 단계별 가이드

├── 🛠️ 03_옵시디언_200%_활용법.md          # 양방향 링크, 태그, 캔버스 활용 가이드

## 🗓️ 3. 4단계 바이브코딩 부업 로드맵 요약

### 1단계: AI와 대화하며 감 잡기 (1~2주차) - "눈치 챙기기"
- 목표: 코딩은 안 짜도 코드가 어떻게 생겼는지는 눈치채기
- 핵심 도구: Antigravity, Claude, ChatGPT, Cursor, GitHub Codespaces/Vercel
- 주요 활동:
  - 프롬프트 한 방으로 첫 웹페이지 띄우기 (HTML/CSS/JS)
  - Vercel이나 GitHub Pages로 1분 만에 무료 배포해보기 (세상에 내 링크 공유)

### 2단계: 첫 번째 디지털 상품 완성 (3~4주차) - "완성의 맛 보기"
- 목표: 실제 작동하는 나만의 디지털 미니 제품 1개 완성하기
- 제품 아이디어 예시:
  - 프리랜서 시급/세금 계산기 웹앱
  - MBTI 스타일의 성향/체질 자가진단 인터랙티브 웹앱
  - 글자 수 세기 & AI 맞춤법 교정 웹 도구
- 배포 & 수익화 준비:
  - 커피 한 잔 후원 버튼(Buy Me a Coffee / 토스 송금 링크) 달기
  - 무료 배포로 피드백 수집 및 트래픽 경험

### 3단계: 유료 디지털 상품 런칭 & 판매 (5~8주차) - "잠잘 때 돈 벌기"
- 목표: 1회 제작 후 계속 팔리는 디지털 자산 구축 (MRR/단발 판매)
- 플랫폼: 크몽, Gumroad, 노션 템플릿 마켓, 포스타입, 와디즈/텀블벅
- 상품군:
  - 업무 생산성 크롬 확장 프로그램 (AI 번역기, 요약기 등)
  - 소상공인/마케터 전용 프롬프트 생성기 웹앱
  - 다운로드형 웹 위젯 / 코드 템플릿 패키지

### 4단계: 외주/프리랜싱 진입 (9~12주차) - "목돈 벌기"
- 목표: 건당 20만~100만 원 외주 수주 및 완수
- 외주 추천 분야:
  - 소상공인/스타트업 이벤트 랜딩페이지 (단기간 집중 제작)
  - 카페/학원/공방 반응형 소개 홈페이지
  - 구글 스프레드시트 연동 견적서 자동 산출 페이지
- 실전 전략:
  - 템플릿 기반 1박 2일 초고속 납품
  - 크몽, 숨고, 지인 네트워크를 통한 초기 레퍼런스 확보
